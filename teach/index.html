Claude Code mods course

42 lessons, one per plugin in this marketplace, ordered by tier: the most useful mods first. Each lesson covers what the mod is, how it was built, with the code, and how to use it.

Start here. Read the API cheat sheet, then lesson 0001. The mod catalogue lists all 109 reviewed mods. Your goal is in MISSION.md, and the full review is in MODS-FINAL-SYNTHESIS.md.

Tier 1 (grade 8)

  • 0001 · Delete guard plugin blast-radius
    These mods guard against a bad delete: they stop a risky shell command such as rm -rf and show what it would remove, or keep a copy so the delete can be undone.
  • 0002 · Delete backup plugin delete-backup
    delete-backup copies the files an rm is about to delete into a backup folder first, so /undo-delete can put the newest deletion back.
  • 0003 · Reflect and memory plugin reflect-mod
    These mods turn a correction you give Claude into a lasting rule, so the next chat starts from what you already taught it. This marketplace ships reflect-mod, which finds the rule in your prompt and offers to save it to CLAUDE.md.
  • 0004 · Mods manager plugin mod-store
    These mods manage your other mods from a pane. This marketplace ships Mod Store: type /mods to search about 2,700 community mods, see what each one can access, and install one after you confirm.
  • 0005 · Mod doctor plugin mod-doctor
    Mod doctor runs the plugin validator on each enabled mod that has a folder, then flags failed checks, shared tool.call hooks and names that are enabled twice.

Tier 2 (grade 7)

  • 0006 · Effort picker plugin effort-picker
    A mod that sets the reasoning effort for each message you send, for that message only, from the words you typed. It never switches the model.
  • 0007 · Assumption check plugin assumption-check
    After a substantial reply, a small Haiku model lists the guesses Claude made, and you mark each one Right or Wrong.
  • 0008 · Secret handling plugin secret-box
    These mods let Claude use an API key without ever seeing it: keys are swapped for placeholders on the way into the chat and back into real values only when a local tool runs.
  • 0009 · Side questions plugin aside
    A read-only side chat, opened with /aside, that answers questions about the session so far without writing anything back into the main conversation.
  • 0010 · Prompt shaping plugin prompt-bouncer
    These mods change or stop a prompt at the moment you press Enter, so that Claude gets a clear request instead of a loose one. This marketplace ships Prompt Bouncer, which drops a vague prompt before Claude sees it and suggests the project's own word.
  • 0011 · Dictation fixer plugin dictation-fixer
    It checks a long typed prompt that looks dictated, asks Haiku for a tidied copy, and lets you choose which version is sent.
  • 0012 · Cache guard plugin cache-tax
    These mods watch Claude's one-hour prompt cache, warn you when it is about to go cold, and in the best version keep it warm during a break or stop one expensive cold send.
  • 0013 · Handoff plugin ctx-handoff
    When a long chat nears a full context, ctx-handoff can have a fork write a summary, runs /clear, and sends the summary into the fresh conversation, so the work carries on without the full history.
  • 0014 · Replay plugin replay-theater
    After Claude changes your files, it lets you step through each edit from the last turn, one diff at a time.
  • 0015 · Screen privacy plugin recording-mode
    Type /rec before you record. Keys, personal details and business figures are masked on screen, private files stay closed, and a red REC shows while it is on.

Tier 3 (grade 6)

  • 0016 · Collision guard plugin collision-guard
    It stops two chats from quietly overwriting each other: before an Edit or Write, it asks Proceed or Cancel if another chat changed that file in the last 30 minutes.
  • 0017 · Session monitor plugin where-am-i
    A live recap of this session above the prompt: the goal, what Claude is doing now, what is waiting on you, and the next step.
  • 0018 · Usage display plugin usage-meter
    usage-meter puts one line above the prompt: your plan's 5-hour and 7-day usage as small bars, when the 5-hour window resets, and what the session has cost.
  • 0019 · Work panel plugin savvy-progress
    savvy-progress shows a progress bar above the prompt and a live panel of subagents: running, finished and planned, with model, task progress, context, estimated cost and time.
  • 0020 · Work inventory plugin mission-control
    mission-control adds /mission: a live map of the main agent, its subagents and every tool call, plus a code map of the files they touch.
  • 0021 · Test-fail magnet plugin test-fail-magnet
    After Claude runs your tests, it lists the failing lines in a pane, with Fix to send them back to Claude and Dismiss to clear them.
  • 0022 · Park and queue plugin prompt-queue
    Park and queue holds a message you type while Claude is busy, and sends it once the current turn ends, so the running turn is not changed.
  • 0023 · Spend and publish guard plugin spend-guard
    spend-guard puts one approval step in front of anything that costs money or publishes: before the call runs, you see what it will do, a short checklist and today's approval count, and you choose Proceed or Cancel.
  • 0024 · You Should Know plugin heads-up
    heads-up is our own small You Should Know: after a long turn, one Haiku call reads the reply and the turn's tool results, and a band above the prompt shows at most two things you might miss, with a Dismiss button.
  • 0025 · Human in the loop plugin human-in-the-loop
    Human in the loop lets Claude hand you the tasks only you can do, and keeps each one in a My tasks pane until you answer it or reject it.
  • 0026 · Diagram pane plugin diagram-pane
    Diagram pane opens a side pane that pins each diagram Claude draws, and keeps a live map of the files and steps in the work.

Tier 4 (grade 5)

  • 0027 · Decision tree plugin decision-tree
    After Claude ends a reply with a question, this family puts the choice in a side pane and lets you explore each option in a forked session.
  • 0028 · Plain English plugin plain-english
    A side pane that rewrites Claude's long replies in plain language, with a short Next steps list, while Claude's own reply stays exactly as it was.
  • 0029 · Prismantis plugin prismantis
    This family redraws Claude Code replies in colour, with coloured tables, headings, code, numbers and links, and draws each tool call as one short line.
  • 0031 · Terminal browser plugin terminal-browser
    This family puts a real web browser in a side pane inside Claude Code, drawn in the terminal, so you can preview pages and let the agent drive it.
  • 0032 · Today's report plugin today-report
    Today's Report totals your Claude Code tasks, the time they would have taken you, and your tokens by day, week, month and year, from your local session logs.

Tier 5 (grade 4)

  • 0033 · Claude Skins plugin skins
    Claude Skins redraws the Claude Code transcript, so tool calls, edits, code, tables and charts each get their own cards and colours.
  • 0034 · Next steps plugin next-steps
    Next steps shows two or three likely next prompts above the prompt after each turn, and lets you press 1, 2 or 3 to draft one.
  • 0035 · Repo heatmap plugin repo-heatmap
    repo-heatmap opens a pane that shows how a repository's files spread across its folders and across kinds such as code, tests, docs, design and data.
  • 0036 · Design picker plugin design-picker
    When Claude asks you to choose a design style, a page opens in your browser with one styled card per option, and then the normal question appears.
  • 0037 · Daily challenge plugin daily-challenge
    daily-challenge gives you one small Claude Code exercise each day, in a pane with a Coach me button and a streak.
  • 0038 · Model router plugin model-router
    A mod that picks haiku, sonnet or opus for each subagent Claude starts without naming a model, from one small Haiku call. The main chat's model never changes.
  • 0039 · Narrator plugin narrator
    After each finished reply, it reads the last 240 characters aloud with the macOS say voice, once you have turned it on with /narrator on.
  • 0040 · Time-lapse plugin time-lapse
    time-lapse records your Claude Code session and replays it as an animated HTML page: the original idea was a video, but this build makes an HTML replay instead.

Tier 6 (toys)

  • 0041 · Cosmetic mods plugin terminal-pet
    terminal-pet puts a small text pet in the band above the prompt, and the pet "eats" the files Claude reads.
  • 0042 · Games and waiting plugin snake
    Games and waiting mods give you something to play or watch while Claude works.
  • 0043 · Panels and toys plugin session-band
    session-band puts the session at a glance in one band above the prompt: turn number, output speed, turn and session cost, a prompt cache countdown and context fill.
