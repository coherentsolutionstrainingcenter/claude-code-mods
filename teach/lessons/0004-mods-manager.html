What it is

Mod Store is an app store for Claude Code mods, inside Claude Code. /mods opens a side pane. You search, filter and sort the catalogue from mods.aidojo.si. Every mod gets an access badge, from green Display only to red Network. Install shows the exact command and the mod's access, and waits for you to confirm. The mod also gives Claude two tools, search_mods and show_mod, so you can ask Claude to find a mod. Claude cannot install anything: you press Install yourself.

Your mission is to explain each mod before other people install it, and Mod Store does the same in code: a mod's page shows what it can access before Install runs anything.

How it was built

The mod is one file, hooks/register.tsx. hooks/hooks.json points to it. types/index.d.ts has the Mod type, one slimmed catalogue record, and the pane's state: query, sort, filter, page, the selected mod, flags for confirming and installing, a status note, and the ids of installed plugins.

1. Register the command and two tools

At session.start the mod registers /mods, with an optional search word. It then registers two tools with $.tool.register. Claude sees them as mcp__mod-store__search_mods and mcp__mod-store__show_mod. Each tool description tells Claude what to do. show_mod says it never installs anything. Last, the hook starts loading the catalogue without waiting for it.

2. Fetch the catalogue in ranges

The catalogue is 7.5 MB, and the host cuts long bodies short. So fetchCatalogText asks for 2,000,000 bytes at a time with a Range header. A 200 reply is the whole file. A 206 reply gives the total size in Content-Range. A character split across two ranges comes back as U+FFFD at the end of the first range. The code drops that tail and starts the next range at the first byte it has not read whole.

/**
 * Reads the whole catalogue a range at a time, since one body is cut short. The host
 * decodes each range on its own, so a character split across two ranges comes back as
 * U+FFFD at the end of the first. That tail is dropped and the next range starts at the
 * first byte not yet read whole.
 */
export async function fetchCatalogText($: Pick<EngineInterface, 'http'>): Promise<string> {
  let text = ''
  let total = Infinity
  let start = 0
  while (start < total) {
    const res = await $.http.fetch(CATALOG_URL, {
      headers: { Range: `bytes=${start}-${start + CHUNK_BYTES - 1}`, 'Accept-Encoding': 'identity' },
    })
    if (res.status === 200) return res.text
    if (res.status !== 206) throw new Error(`HTTP ${res.status}`)
    const size = /\/(\d+)\s*$/.exec(res.headers['content-range'] ?? '')
    if (!size) throw new Error('the server sent no Content-Range')
    total = Number(size[1])
    const isLast = start + CHUNK_BYTES >= total
    const whole = isLast ? res.text : res.text.replace(/�+$/, '')
    if (whole === '') throw new Error(`no readable text at byte ${start}`)
    text += whole
    start += isLast ? CHUNK_BYTES : utf8Bytes(whole)
  }
  return text
}

3. Keep a slim copy for six hours

loadCatalog keeps the catalogue in the plugin's store, under catalog-v2, with the time it was saved. A copy younger than six hours is used as it is. Otherwise the mod fetches again, turns each record into a Mod with slim, and drops repeated ids. slim keeps only records of kind mod that are not archived. It sets marketplace only when the repository has a working .claude-plugin/marketplace.json at its root. If the fetch fails, the pane shows the reason.

async function loadCatalog($: EngineInterface, force = false) {
  const cached = (await $.store.get(CACHE_KEY)) as { at: number; mods: Mod[] } | undefined
  if (cached && catalog.length === 0) {
    catalog = cached.mods
    await update($, loadedAt, () => cached.at)
  }
  const now = await $.clock.now()
  if (!force && cached && now - cached.at < MAX_AGE_MS) return

  await update($, status, () => (catalog.length ? 'Refreshing…' : ''))
  try {
    const data = JSON.parse(await fetchCatalogText($))
    const mods: Mod[] = []
    const seen = new Set<string>()
    for (const record of data.mods ?? []) {
      const mod = slim(record)
      if (!mod || seen.has(mod.id)) continue
      seen.add(mod.id)
      mods.push(mod)
    }
    catalog = mods
    await $.store.set(CACHE_KEY, { at: now, mods })
    await update($, loadedAt, () => now)
    await update($, status, () => '')
  } catch (error) {
    const why = error instanceof Error ? error.message : String(error)
    await update($, status, () => `Couldn't load the catalogue (${why})`)
  }
}

4. Search, filter and sort

select serves both the pane and Claude's tool. Every word of the query must appear in a mod's name, description, author or repository. The filters keep one-click installs, display-only mods, panes or bands. Stars belong to a repository, not a mod, so one big repository could fill every page. The star sort therefore takes each repository's best mod first, then each one's second, and so on.

/** The mods a query, filter and sort select, in order. */
export function select(mods: Mod[], q: string, f: Filter, s: Sort): Mod[] {
  const words = q.toLowerCase().split(/\s+/).filter(Boolean)
  const kept = mods.filter(mod => {
    if (f === 'installable' && !mod.marketplace) return false
    if (f === 'safe' && mod.level > 0) return false
    if (f === 'pane' && !mod.draws.includes('Pane')) return false
    if (f === 'band' && !mod.draws.includes('AbovePrompt')) return false
    const hay = `${mod.name} ${mod.description} ${mod.author} ${mod.repo}`.toLowerCase()
    return words.every(w => hay.includes(w))
  })
  const order: Record<Sort, (a: Mod, b: Mod) => number> = {
    stars: (a, b) => b.stars - a.stars || a.name.localeCompare(b.name),
    new: (a, b) => b.createdAt.localeCompare(a.createdAt),
    name: (a, b) => a.name.localeCompare(b.name),
  }
  const sorted = kept.sort(order[s])
  if (s !== 'stars') return sorted
  // Stars belong to a repo, not a mod: one big repo with 45 mods would fill
  // every page. Take each repo's best first, then each one's second, and so on.
  const seen = new Map<string, number>()
  const turn = new Map(sorted.map(mod => {
    const n = seen.get(mod.repo) ?? 0
    seen.set(mod.repo, n + 1)
    return [mod, n] as const
  }))
  return sorted.sort((a, b) => turn.get(a)! - turn.get(b)! || order.stars(a, b))
}

5. Answer Claude's search

A tool that the mod registers is served by a tool.call hook on its full name. The hook returns { result } with text for Claude, or { deny } when the catalogue is not loaded. It returns 10 mods by default and 25 at most. Each line says the mod's id, author, stars, access and whether it installs in one click.

  on('tool.call', { tool: 'mcp__mod-store__search_mods' }, async ($, e) => {
    const input = e as unknown as { query?: string; filter?: Filter; limit?: number }
    await loadCatalog($)
    if (catalog.length === 0) return { deny: (await read($, status)) || 'The mod catalogue is not loaded yet.' }
    const limit = Math.min(25, Math.max(1, Math.round(input.limit ?? 10)))
    const found = select(catalog, input.query ?? '', input.filter ?? 'all', 'stars')
    const owned = new Set(await read($, installed))
    const text = found.length
      ? `${found.length} match${found.length === 1 ? '' : 'es'}, best ${Math.min(limit, found.length)}:\n` +
        found.slice(0, limit).map(mod => describe(mod, owned)).join('\n')
      : 'No mods match. Try one shorter keyword or a synonym.'
    return { result: text }
  })

7. Run the install command

install runs claude plugin install with $.process.run and a 120-second limit. On success, a toast says to run /reload-plugins, and the mod reads claude plugin list --json again to mark the mod as installed. On failure, the pane shows the last three lines of the output.

async function install($: EngineInterface, mod: Mod) {
  if (!mod.marketplace) return
  await update($, isBusy, () => true)
  await update($, status, () => '')
  try {
    const { exitCode, stdout, stderr } = await $.process.run(
      ['claude', 'plugin', 'install', mod.name, '--marketplace', mod.repo],
      { timeoutMs: 120_000 },
    )
    if (exitCode === 0) {
      $.ui.toast(`Installed ${mod.name}. Run /reload-plugins to load it.`)
      await loadInstalled($)
    } else {
      const why = (stderr || stdout).trim().split('\n').slice(-3).join(' ')
      await update($, status, () => `Install failed: ${why}`)
    }
  } catch (error) {
    await update($, status, () => `Install failed: ${error instanceof Error ? error.message : error}`)
  }
  await update($, isConfirming, () => false)
  await update($, isBusy, () => false)
}

How to use it

claude plugin marketplace add <org>/waraxe-claude-mods
claude plugin install mod-store@waraxe-claude-mods

Then run /reload-plugins and type /mods. The README says it needs a Claude Code version with mods, and it was tested on 2.1.292.

  • Type /mods to open the pane, or /mods spotify to open it with a search.
  • Type in the search box. Press a chip to filter: All, One-click, Display only, Panes or Bands. Pick a sort: Most stars, Newest or A to Z.
  • Open a card to read the mod's page: its access badge, what it can access, where it shows up, and its validation result.
  • Press i to install, then y to confirm. Press b to go back to the list. Tab or the arrows and Enter move between items and open one.
  • After an install, run /reload-plugins to load the new mod.
  • Or ask Claude, for example "find me a mod that shows my Spotify song". Claude searches, compares a few, and opens its pick in the pane. The ✦ Ask Claude button in the pane sends that kind of request for your search words. With no search words, it starts the request in the prompt box for you to finish.

Settings. The README lists none.

Cost. The mod makes no model calls of its own. Asking Claude is a normal turn. The mod uses the network to fetch the catalogue, in pieces, and keeps a slimmed copy for six hours. It runs claude plugin list and claude plugin install. The README says it reads nothing else on your machine.

Limits.

  • It needs the network. If the catalogue does not load, the pane shows the reason and a Retry button.
  • One-click install works only for a mod whose repository has a marketplace at its root.
  • Stars are the whole repository's, shared by all its mods.
  • A mod that the catalogue does not grade is shown as Writes & runs.
  • A comment in the code says the mobile app draws no fields yet, so there is no search box or sort there.
  • An installed mod loads only after /reload-plugins.

Check yourself

Can Claude install a mod through Mod Store's two tools?

No. search_mods returns text. show_mod opens the mod's page in the pane, and its description says it never installs anything. Only the pane's Install button, then Confirm install, runs install. The README adds that installs never use -y, so a marketplace's own commands are never auto-accepted.

Why does fetchCatalogText fetch the catalogue in ranges, and what does it do with U+FFFD?

The host cuts long bodies short, and the catalogue is 7.5 MB, so it asks for 2,000,000 bytes at a time. Each range is decoded on its own, so a character split across two ranges ends the first one as U+FFFD. The code drops that tail, counts the UTF-8 bytes it kept, and starts the next range there.
