What it is

Prismantis is one mod with a hook module of 856 lines. It registers its own drawing for assistant replies, user prompts, tool rows and command output. When it has nothing to draw, it passes the event on with next(e), so Claude Code's own drawing or another mod can take over.

It matters for your mission because it uses ten different event names and also exposes an API to other mods, which is the case you must explain when you list a mod's hooks and calls.

How it was built

The hook module is 856 lines. This page covers its hook registrations and its types file. It does not cover the drawing code in render.tsx. The steps follow the order in the file.

1. Add the placeholder and read the options

The engine.create hook adds a prismantis.markdown placeholder that returns undefined. If enabled is false, the register function stops there, so the placeholder stays. Otherwise it picks the theme and builds one style object from the options. random picks a dark preset each time the mod loads, as plugin.json says.

export const register: Register = (on, options) => {
  on('engine.create', async (_$, e, next) => ({ ...(await next(e)), prismantis: { markdown: async () => undefined } }))
  if (options.enabled === false) return
  const firstTheme = pickTheme(options.theme)
  const style = resolveStyle({ ...options, theme: firstTheme })

2. Draw tool calls as one line

This block runs only when the toolRows option is not false. The ToolUse hook draws a compact row, such as Read ~/src/app.ts. When the row is expanded, shell calls get their own expanded drawing. Other calls pass to Claude Code's drawing.

    on('ui.render', { component: 'ToolUse' }, async ($, e, next) => {
      await locate($, style)
      noteCommand(e.props.tool_use_id, e.props.tool, e.props.input)
      if (quiet && isReadOnlyCall(e.props.tool, e.props.input)) rememberCall(readOnlyCalls, e.props.tool_use_id)
      if (!expandedCalls.has(e.props.tool_use_id)) return renderToolRow($.ui.resolve(e), forSurface(style, e, await linkReach($, probes, style)), e.props, e.viewport?.columns)
      const shell = e.props.tool === 'Bash' || e.props.tool === 'PowerShell'
      return shell && typeof e.props.output !== 'string' ? renderExpandedShell($.ui.resolve(e), style, e.props, e.viewport?.columns) : next(e)
    })

3. Handle the /prismantis command

session.start registers the command. The command.run hook, matched on { command: 'prismantis' }, reads the arguments. It handles demo, setup, copy and theme. A theme name is checked against the list before anything changes.

  on('command.run', { command: 'prismantis' }, async ($, e) => {
    const [first, second, third] = e.args.trim().split(/\s+/)
    const [sub, name] = THEME_ARGS.includes(first ?? '') ? ['theme', first] : [first, second]
    if (sub === 'demo') return { text: showcaseText(PRESET_NAMES) + languageShowcase(await localeOf($, name)) }
    if (sub === 'setup') return { text: await setup($, picked, e.origin, name, third) }
    if (sub === 'copy') {
      const reply = (await $.session.messages()).findLast(m => m.role === 'assistant' && m.text.trim())
      if (!reply) return { text: 'Nothing to copy yet.' }
      const code = name === 'code' ? nestedBlocks(parseCached(reply.text)).findLast(b => b.kind === 'code') : undefined
      if (name === 'code' && code?.kind !== 'code') return { text: 'The last reply has no code block.' }
      const result = await $.ui.copy({ text: code?.kind === 'code' ? code.lines.join('\n') : reply.text })
      return { text: result.isCopied ? `Copied the last ${code ? 'code block' : 'reply'}.` : `Copy failed: ${result.reason}` }
    }
    if (sub === 'demo-rtl') {
      await probe($, style, probes)
      return { text: rtlShowcaseText() }
    }
    if (sub !== 'theme') return { text: helpText(PRESET_NAMES) }
    if (!name) return { text: options.theme === 'random' ? `current: ${picked.theme} (random)\nkeep it: /prismantis theme ${picked.theme}` : `current: ${picked.theme}` }
    if (!THEME_ARGS.includes(name)) return { text: `Unknown theme "${name}". Themes: ${PRESET_NAMES.join(', ')}, random` }
    return { text: await setTheme($, picked, name) }
  })

4. Draw assistant replies

The AssistantMessage hook parses the reply text into blocks. If there are none, it passes the event on. Otherwise it draws the blocks with drawMarkdown, and wraps them with renderReply, which comes from render.tsx.

  on('ui.render', { component: 'AssistantMessage' }, async ($, e, next) => {
    const blocks = parseCached(e.props.text)
    if (blocks.length === 0) return next(e)
    const el = $.ui.resolve(e)
    const narration = style.toolStyle === 'tree-bold' && blocks.length === 1 && blocks[0]!.kind === 'paragraph'
    const reach = await linkReach($, probes, style)
    const math = await mathOfBlocks($, latex, e.surface, blocks)
    const pictures = await picturesOf($, style, probes, e.surface, blocks)
    const surfaceStyle = { ...(await withFoundPaths($, pathChecks, forSurface(style, e, reach), blocks)), images: await imagesOn($, probes, e.surface) }
    const open = await read($, unfolded)
    const reply = blocks.length > 1 || hasRtl(e.props.text) ? e.props.text : undefined
    const corner = reply !== undefined && markerRoom(surfaceStyle) > 0
    const columns = columnsOf(e.viewport)
    const framed = replyStyleFor(surfaceStyle, e.props.text)
    const drawn = drawMarkdown($, el, narration ? { ...surfaceStyle, narration } : surfaceStyle, blocks, columns - replyRoom(framed), math, pictures, reply, open, { id: e.requestId, press: reach.marks })
    return renderReply(el, framed, drawn, e.props.isFirstOfReply === true, columns, corner)
  })

5. Let other mods draw Markdown

The prismantis.markdown hook answers calls made as $.prismantis.markdown({ surface, text, columns }). It returns a drawn element, or passes the event on when the text has no blocks. Copy buttons are turned off for these calls, because a button cannot cross from one mod's output into another's.

  on('prismantis.markdown', async ($, e, next) => {
    const blocks = parseCached(e.text, shared, 20)
    if (blocks.length === 0) return next(e)
    const el = $.ui.resolve({ surface: e.surface, component: 'AssistantMessage' })
    const { Box } = el
    const surfaceStyle = forSurface(style, e, await linkReach($, probes, style))
    return { value: <Box flexDirection="column" rowGap={1} {...fullWidth(e.text)}>{drawMarkdown($, el, { ...surfaceStyle, copyButtons: false }, blocks, Math.max(20, e.columns || 0))}</Box> }
  })

6. Declare the types for other mods

types/index.d.ts declares the argument and return types of that call. The README says a mod that lists prismantis under dependencies gets these types. A mod that treats prismantis as optional can declare its own copy instead.

export type PrismantisMarkdownArgs<Surface> = {
  surface: Surface
  text: string
  columns: number
}

export type Prismantis<Surface, Drawing> = {
  markdown: (args: PrismantisMarkdownArgs<Surface>) => Promise<Drawing | undefined>
}

How to use it

claude plugin marketplace add NahumLitvin/prismantis
claude plugin install prismantis@prismantis

The marketplace name is prismantis, from .claude-plugin/marketplace.json. The README says it needs Claude Code 2.1.287 or later.

  • Run /prismantis setup to pick a theme and styles from drawn samples. Run /prismantis demo for a tour of the main features.
  • Run /prismantis theme <name> to switch the theme at once. Run /prismantis copy to copy the last reply, or /prismantis copy code to copy its last code block.
  • To change an option, set it under pluginConfigs, then "prismantis@prismantis", then "options", in ~/.claude/settings.json. Then run /reload.
  • To turn it off, set "enabled": false in the options, or disable the plugin in /plugin. Claude Code's own renderer comes back.

Cost. The hook code makes no network calls. A search of hooks/ finds no fetch or HTTP client. Two programs can run. One is the LaTeX renderer, and only while latex is on. The other is the clipboard helper, which the README says runs only on a click. By default, diagramHints adds a short hidden note to each prompt you type. The README puts that at about 630 tokens, which is a model cost on every prompt.

Limits. The README lists these.

  • The parser covers what Claude writes. It is not full CommonMark. HTML draws as plain text, and a quote ends at the first line without a quote mark.
  • Widths count CJK and emoji as two columns. Some emoji may still be one column off, because terminals disagree.
  • Languages outside its 24 known ones draw in the theme's code text colour.
  • It was tested by hand in the macOS terminal. CI runs the tests on macOS, Linux and Windows. The desktop app, VS Code and mobile are not yet checked by hand.

Check yourself

What does next(e) do in these hooks, and why does prismantis use it?

It passes the event to the next handler, which is Claude Code's own drawing or another mod. Prismantis does this when it has nothing to draw. For example, an assistant reply with no blocks passes through, and so does an expanded tool call that is not a shell command.

Why does the prismantis.markdown hook turn off copy buttons?

The README says a copy button cannot cross from one mod's output into another. The code sets copyButtons: false for these calls, so no button appears in the drawn element.
