What it is

Snake is a small game that runs in a pane while Claude works. It stays off until you type /snake, and it pauses when Claude's turn completes. The rules sit in snake.ts as plain functions, so the tests can run them without a pane.

It is a toy. It does not serve the mission and is included for completeness.

How it was built

Snake has three parts: the rules in snake.ts, the pane in game.tsx, and the hooks in register.tsx. The steps below follow that order. Each snippet is copied from the clone.

1. Hold the game's values in host atoms

register.tsx creates four atoms. The host keeps them, so a hot reload keeps the game's mode and scores.

// Held by the host, so a hot reload keeps the game's mode and scores.
const isPlaying = atom({ plugin: 'snake', key: 'isPlaying' } as const, false)
const score = atom({ plugin: 'snake', key: 'score' } as const, 0)
const best = atom({ plugin: 'snake', key: 'best' } as const, 0)
const isOn = atom({ plugin: 'snake', key: 'isOn' } as const, false)

2. Turn it on and off with /snake

The command.run hook handles /snake. A bare /snake toggles the game. on and off say which state you want. If Claude is working when you turn it on, the game plays at once. Otherwise it waits for the next turn.

  on('command.run', { command: 'snake' }, async ($, e) => {
    const arg = e.args.trim().toLowerCase()
    if (!['', 'on', 'off', 'stop'].includes(arg)) return { text: 'usage: /snake toggles it, /snake on or /snake off says which' }
    // A bare /snake toggles; `stop` and `on` say which.
    const isOff = arg === 'stop' || arg === 'off' || (arg !== 'on' && (await read($, isOn)))
    if (isOff) {
      await update($, isOn, () => false)
      await update($, isPlaying, () => false)
      await $.ui.close({ id: PANE })
      return { text: 'Snake is off. /snake (or /snake on) turns it back on.' }
    }
    await update($, isOn, () => true)
    await update($, isPlaying, () => isWorking) // turned on mid-turn: play now, not next turn
    await $.ui.open({ id: PANE, title: 'Snake', focus: true })
    return { text: 'Snake is on. It plays while Claude works. /snake again turns it off.' }
  })

3. Play while a turn runs, and pause when it ends

The turn.start hook sets the game to play, if it is on. The turn.complete hook stops play when the main agent's turn ends. It checks e.agentId, so a sub-agent finishing does not pause the game.

  on('turn.start', async ($, e, next) => {
    isWorking = true
    if (!(await read($, isOn))) return next(e) // opt-in: nothing until /snake
    await update($, isPlaying, () => true)
    void $.ui.open({ id: PANE, title: 'Snake' }) // seats from 144 columns when opened unasked; /snake opens it at any width
    return next(e)
  })

  on('turn.complete', async ($, e, next) => {
    const r = await next(e)
    if (!e.agentId) {
      isWorking = false
      await update($, isPlaying, () => false)
    }
    return r
  })

4. Keep the rules pure

snake.ts holds the rules as functions with no $ and no timers. step moves the snake one cell. It returns whether food was eaten and whether the snake crashed. A crash starts a new game with score zero.

export function step(game: Game): { game: Game; ate: boolean; crashed: boolean } {
  const dir = game.nextDir
  const head = game.snake[0]!
  const next = { x: head.x + MOVES[dir].x, y: head.y + MOVES[dir].y }
  const ate = next.x === game.food.x && next.y === game.food.y
  const body = ate ? game.snake : game.snake.slice(0, -1)

  const hitWall = next.x < 0 || next.y < 0 || next.x >= game.cols || next.y >= game.rows
  const hitSelf = body.some(c => c.x === next.x && c.y === next.y)
  if (hitWall || hitSelf) {
    return { game: newGame(game.cols, game.rows, game.seed), ate: false, crashed: true }
  }

  const snake = [next, ...body]
  if (!ate) return { game: { ...game, snake, dir }, ate, crashed: false }
  const placed = placeFood(game.cols, game.rows, snake, game.seed)
  return { game: { ...game, snake, dir, food: placed.food, seed: placed.seed, score: game.score + 1 }, ate, crashed: false }
}

5. Run the clock and keys inside the pane

The pane is a client module, game.tsx. It has its own clock, surface.every, which fires every 120 ms. Each tick checks the pane size, and it steps the game only while isPlaying is true. Arrow keys and W, A, S, D set the next direction through surface.onKey.

  if (surface.state === undefined) {
    const local: Local = { game: null, live: { props } }
    surface.every(TICK_MS, () => {
      const now = surface.state
      if (!now) return
      const size = gridSize(surface.columns, surface.rows)
      if (size.cols < MIN_COLS || size.rows < MIN_ROWS) return
      if (!now.game || now.game.cols !== size.cols || now.game.rows !== size.rows) {
        surface.setState({ ...now, game: newGame(size.cols, size.rows, Date.now() % 100000) }) // a new or resized pane
        return
      }
      if (!now.live.props.isPlaying) return
      const r = step(now.game)
      if (r.ate || r.crashed) surface.post({ score: r.game.score })
      surface.setState({ ...now, game: r.game })
    })

6. Post the score back and save the best

The pane sends its score with surface.post whenever the snake eats or crashes. The ui.message hook sets the score atom. If it beats the best, the hook saves the new best in the plugin store under the key best.

  // The game posts its score whenever it eats or crashes.
  on('ui.message', async ($, e) => {
    const data = e.data as { score?: unknown }
    if (e.element !== 'snake' || typeof data?.score !== 'number') return {}
    const now = data.score
    await update($, score, () => now)
    const before = await read($, best)
    if (now > before) {
      await update($, best, () => now)
      await $.store.set(BEST_KEY, now)
    }
    return {}
  })

7. Test the rules without a pane

The tests call newGame, step and turn directly. This test checks that a wall ends the game and resets the score.

  test('a wall resets the game', () => {
    let g = at(newGame(20, 10), { x: 0, y: 0 })
    let crashed = false
    for (let i = 0; i < 20 && !crashed; i++) {
      const r = step(g)
      g = r.game
      crashed = r.crashed
    }
    expect(crashed).toBe(true)
    expect(g.snake.length).toBe(3)
    expect(g.score).toBe(0)
  })

How to use it

claude plugin marketplace add hamzafer/claude-code-mods
claude plugin install snake@claude-code-mods
  • Type /snake. The pane opens with focus. The game moves only while a Claude turn runs, so if Claude is idle it waits for the next turn.
  • Steer with the arrow keys or W, A, S and D. A turn straight back on itself is ignored. The engine's types say Escape hands the focus back.
  • When the turn ends, the game pauses and the pane says that Claude is done and it is your turn.
  • While the game plays with a score above zero, the spinner line shows the score and the best score.
  • Type /snake again, or /snake off or /snake stop, to turn it off.

What it costs. The source makes no model calls and no network calls. The pane's clock fires every 120 ms while the pane is open, and it moves only when a turn is running. The best score is kept in the plugin store.

Limits.

  • It runs only in the terminal or the desktop app. Other surfaces see one line of text.
  • The board needs at least 10 by 6 cells. Each cell is two columns wide, and two rows go to the header and footer, so the pane needs roughly 20 columns and 9 rows. A smaller pane shows "Make the pane bigger to play".
  • A wall or the snake's own body ends the game. The board restarts at three cells with score zero. The best score stays.
  • I did not install or run it, so none of this is tested here.

Check yourself

What stops Snake when Claude finishes?

The turn.complete hook sets isPlaying to false, but only for the main agent, because it checks that there is no agentId. The game then stops stepping. The pane shows that it is paused.

Where is the best score kept?

In two places. The best atom holds it while the host runs. The plugin store keeps it under the key best. session.start reads the stored value back, and ui.message saves a new best.
