Mod API cheat sheet

The parts of the hook API that our mods use, checked against the engine's type file for build 2.1.308. Look a name up here, then grep the type file for its full doc comment.

Plugin folder

.claude-plugin/plugin.json
name, version, description, author, license, and optional types and userConfig.
hooks/hooks.json
{ "modules": ["./register.ts"] }. The path is relative to this file.
hooks/register.ts or .tsx
exports register: Register. Use .tsx only when the mod draws panes with JSX.
types/index.d.ts
only when the mod keeps state in atoms. Declares each atom in PluginState.
README.md, LICENSE
read by people who install the mod. The marketplace root holds one LICENSE.

The hook shape

on('event', matcher?, async ($, e, next) => {
  // $   the engine interface: $.noun.method(...)
  // e   the event's input, a frozen plain value
  // next(e)  runs the other hooks, then the engine's own behaviour
})
  • A hook that returns without calling next answers for itself.
  • next({ ...e, text }) rewrites what the rest sees.
  • Spell on(...) and $.noun.method(...) literally in the source. The validator reads them from the text.

Shapes of a result

  • Deny a tool call: return { deny: 'reason' }. The model reads the reason as an error.
  • Answer a command: return { text: 'message' }.
  • Draw a pane: return one element tree from the ui.render hook, built with $.ui.resolve(e).

Glossary

Mod
a plugin that uses hooks to change how Claude Code behaves.
Marketplace
a folder or repository that lists plugins, with a marketplace.json.
Hold
a hook waits for a decision before it lets a tool call run. Blast Radius and collision-guard do this.
Fail open
when a hook breaks, the call goes ahead.
Fail closed
when a hook breaks, the call is refused.
Composer prompt
a prompt the person typed at the terminal (origin.kind === 'composer').
Validator
claude plugin validate <folder>. It checks the structure and lists the events and calls a mod declares. It does not run the mod.

Where the full API lives

The engine's type file is engine/types/claude-code.d.ts. It has about 22,000 lines. Grep it for an event name, a noun or a method. The file is written for this build, so check the version before you rely on it.
